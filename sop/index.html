Standard operating procedure

Adding a new club to the app

One app, one Cloudflare project and one database per club. Every club updates when the shared code is updated.

  • About 10 minutes per club
  • Free tier
  • No coding needed

Clubs share the code but never see each other's results, players or photos. Each club has its own admin PIN, name, colours and badge, all set inside the app.

Before you start

  • You can log in to Cloudflare and to GitHub.
  • The club's name and a short name for the home screen (for example "Norton Ancients" and "Ancients").
  • A short lower-case name to use everywhere (for example norton). Use letters only.
  • The club's badge as a PNG or JPEG.
Shortcut: steps 1 and 2 can be done by Claude. Say "Add a club called <name>" and give the short name and club name. You still do step 3 in Cloudflare, because creating the project needs the dashboard.
1

Create the club's database

  1. In Cloudflare go to Storage & databases → D1 SQLite Database → Create database.
  2. Name it <club>-trial and create it. Choose Western Europe if it asks for a location.
  3. Open the database and click the Console tab (marked 1 below).
  4. Open worker/schema.sql in the GitHub repository, copy the whole file, paste it into the Console and run it.
  5. Then run this, with the club's real names: 
    UPDATE club_settings SET club_name='Norton Ancients', short_name='Ancients' WHERE id=1;
  6. Copy the database ID shown on the Overview page (the long code with dashes). You need it in step 2.
Check: the Overview shows Number of Tables: 9. If it shows 0, the schema did not run.
2

Add the club's two small files

In the GitHub repository, copy the folder clubs/norton to clubs/<club> and edit the two files inside.

clubs/<club>/club.json

The name shown under the home-screen icon, and the colour of the phone's top bar.

clubs/<club>/wrangler.jsonc

Change these three values and leave the rest alone:

"name": "<club>",
"database_name": "<club>-trial",
"database_id": "paste the ID from step 1"
The name must be exactly the same as the Cloudflare project name in step 3. If they differ, the build fails with a name mismatch error.

Commit the change to the same branch the other clubs use (currently cloudflare-trial).

3

Create the Cloudflare project

  1. Cloudflare → Workers & Pages → Create → Import a repository, and pick the app's repository.
  2. Project name: exactly the name from step 2.
  3. Build command: CLUB=<club> npm run build
  4. Deploy command: npx wrangler deploy -c clubs/<club>/wrangler.jsonc
  5. Leave everything else as it is and save.
Set the production branch. Open the project → Settings → Builds → Branch control and choose the branch every club builds from (currently cloudflare-trial). If you skip this, Cloudflare builds main, which has no club files, and the build fails with a message about a Vite version that "cannot be automatically configured".
If a build fails and you fix it: clicking Retry re-runs the old version. Push a new commit instead (an empty one is fine) to start a fresh build.
4

Check it works

  1. Wait for the build to finish (a couple of minutes, shown as green in Deployments).
  2. Open https://<club>.<your-account>.workers.dev.
  3. You should see the club's name at the top, a season (2026/27) and "No results logged yet".
  4. Tap the padlock, enter the starting PIN and make sure the Staff Room opens.
Done. Send the club the section below.
Send this part to the club

Getting started – your first 5 minutes

Your app address: ________________________
Your starting admin PIN: __________ (change it in step 2 below)

1. Open the Staff Room

Tap the padlock at the top right, then enter your PIN.

2. Change your PIN straight away

On the Branding screen, scroll down to Admin PIN. Type a new PIN of 4 to 8 digits, tap Change, and share it only with the people who log results.

3. Upload your club badge

Still on Branding, tap Upload badge and choose your crest (PNG or JPEG), then tap Save branding. You can also change the colours, club name and slogan here.

4. Add the app to your home screen – after the badge

  • iPhone: open the address in Safari, tap the Share button, then Add to Home Screen.
  • Android: open it in Chrome, tap the three dots, then Install app or Add to Home screen.
Do this after uploading the badge. The home-screen icon is copied when the app is added. If it was added earlier and shows the wrong icon, delete it from the home screen and add it again.

Updating every club

Push a change to the shared branch. Each club's Cloudflare project rebuilds and deploys it on its own. You do not touch the clubs one by one.

If a change adds a new database column: add a numbered file in worker/migrations/ and run it in the Console of every club's database before you push. Otherwise that club's app breaks until you do.

When something goes wrong

You seeWhy, and what to do
Build fails: "name mismatch" or the Worker name is wrongThe name in the club's wrangler.jsonc does not match the Cloudflare project name. Make them identical and push a new commit.
Build fails: "Vite … cannot be automatically configured"Cloudflare is building a branch with no club files. Set the production branch under Settings → Builds → Branch control.
Retry keeps failing the same wayRetry re-runs the old commit. Push a new commit to start a fresh build.
The app says "Connection error" on first openThe database has no starting season. Run the last line of worker/schema.sql (the INSERT INTO seasons line) in the Console. Databases made from the current schema already have it.
Data does not load at allThe database ID in wrangler.jsonc is wrong or the schema was not run. Check Number of Tables is 9.
Home-screen icon shows another club's badgeThe club installed the app before uploading their badge. Upload the badge, then delete and re-add the app on the phone.
Forgotten admin PINAsk Claude to reset it, or set it directly in the database. It is stored only as a hash, so it cannot be read back.
Image upload says it failedImages are limited to about 1.2 MB after shrinking. Use a smaller photo. BMP files are not supported; use PNG or JPEG.

Free-tier limits to keep an eye on

  • The number of D1 databases allowed on a free Cloudflare account (around 10 at the time of writing).
  • Daily Worker requests, shared by every club on the account.
  • Monthly build minutes. Every push rebuilds every club, so many small pushes use them up faster.

Check Cloudflare's current free-plan limits before taking on a lot of clubs. At around five or more clubs it is worth looking at usage.

New club checklist

  • Database created and schema run (Number of Tables: 9)
  • Club name and short name set in the database
  • clubs/<club>/ files edited and committed
  • Cloudflare project created with the same name, build and deploy commands
  • Production branch set under Branch control
  • Build green and the app opens with the right club name
  • Club sent the "getting started" section
  • Club has changed the PIN and uploaded their badge, then added the app to their home screen
